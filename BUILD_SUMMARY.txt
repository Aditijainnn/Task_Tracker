🚀 QUICK START
================================================================================

1. Setup Backend:
   $ cd backend
   $ npm install
   $ npm run dev
   
   ✓ You should see: "✓ Server running on http://localhost:5000"

2. Setup Frontend:
   $ cd mobile
   $ npm install
   $ npm start
   
   ✓ Scan QR code with Expo Go app on your phone

3. Test the App:
   - Signup with: test@example.com / password123
   - Create a task
   - Mark it complete
   - Delete it
   - Logout

🔧 CONFIGURATION REQUIRED
================================================================================

1. MongoDB URI (backend/.env):
   MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/task-tracker?retryWrites=true&w=majority

2. API Base URL (mobile/services/api.ts):
   const API_BASE_URL = 'http://YOUR_IP:5000/api';
   
   Replace YOUR_IP with your machine's local IP address

3. Get your IP:
   macOS/Linux: ifconfig | grep "inet " | grep -v 127.0.0.1
   Windows: ipconfig
